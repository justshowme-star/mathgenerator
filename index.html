Math Grapher Help

Typing Equations, Points & Sliders

Type equations, inequalities, or points in any row: y = 2x + 1, x = 4, x² + y² = 9, f(x) = x², or A(2, 3), B(−1, 4). Use the symbol toolbar or type ^2, <=, >=, !=, sqrt(), and pi to format automatically.

Single letters other than x, y, e, i, j, l, o (such as a, b, c, h, k, m) automatically create interactive sliders with adjustable min, max, and step bounds.

Row Styling, Labels & Teacher Modes

  • Click a row’s colored circle to show or hide it; press and hold (or right-click) to change its color.
  • Expand a row for Line style (dashed, dotted, thickness, arrows) and Label placement, or drag labels directly on the graph (double-click a label to reset its position).
  • Use ⋯ → Answer key only to mark solution rows, then toggle Key | Student and Color | B&W in the top toolbar for worksheets and photocopying.

Navigation, Graph Settings & Exporting

  • Drag to pan, hold Ctrl (Cmd on Mac) + scroll (or use +/−) to zoom, and click a plotted line or point to jump to its row. On touch screens, tap ✥ to drag the graph.
  • Click the gear button for Graph settings (axis bounds, step sizes like pi/2, decimal/π/degree ticks, grid lines, and radians/degrees) or pick a preset from Template….
  • Use Copy for Docs or Copy as image under any equation (piecewise functions copy as a borderless aligned table). Open Export ▾ to save PNG (1×–4×) or SVG, print, or adjust $ … $ wrappers. Save and Load export .json files, and work autosaves locally with Ctrl+Z / Ctrl+Shift+Z.

Coordinate Points & 1D Number Lines

  • Plot ordered pairs as (2, 3) or named points A(2, 3), B(−1, 4). Name multiple points in the Label box as A; B; C and check Show coordinates.
  • Turn on Number line mode (1D) in Graph settings (or choose a Number line template) to plot 1D points A(−3), B(2) and compound inequalities such as −2 ≤ x < 4 or x ≠ 3.

Linear Relations & Systems of Equations

  • Graph lines in slope-intercept (y = −2x + 5), standard (3x − 2y = 6), horizontal (y = 4), or vertical (x = −2) form.
  • Open Key points & symmetry on a row to display x-intercepts, y-intercept, and POI (intersections) where lines or curves cross.

Quadratics, Circles & 2D Inequalities

  • Graph parabolas in vertex (y = a(x − h)² + k), factored (y = (x − 3)(x + 1)), or standard (y = x² − 4x + 3) form, and toggle Vertex / turning points and Axis of symmetry.
  • Graph circles centered at the origin (x² + y² = 25) or translated ((x − 2)² + (y + 1)² = 16).
  • Use <, >, ≤, or ≥ (e.g., y ≥ x − 3) for 2D inequalities, and use Where inequalities overlap to shade or cross-hatch feasible regions.

Functions, Domain Restrictions & Piecewise

  • Define named functions such as f(x) = x² − 4 and transform them in other rows (y = −2f(x − 1) + 3).
  • Restrict domains or ranges with braces: y = x² {x ≥ 0} or y = x + 1 {−2 ≤ x < 4} (automatically draws open and filled endpoint circles).
  • Click Piecewise for the visual fill-in editor, or enter inline: f(x) = {x < 0: x + 1, 0 ≤ x < 2: x², 3}.

Inverses, Rational, Exponential & Logarithmic Functions

  • Expand Inverse function on any function row to plot f−1(x) along with the dashed y = x reflection line.
  • Rational functions such as y = (x² − 1)/(x − 1) or y = 1/(x − 2) + 3 automatically highlight vertical, horizontal, and slant asymptotes as well as holes.
  • Plot exponential and logarithmic curves: y = 2^x, y = e^x, y = ln(x), y = log(x), and y = log_2(x).

Trigonometry, Parametric, Vectors & Calculus

  • Graph sin, cos, tan, sec, csc, cot, and inverse trig (arcsin, arccos, arctan) in radians or degrees (switch in Graph settings or via the trig templates).
  • Plot parametric curves with parameter t: (cos(t), sin(t)) {0 ≤ t ≤ 2pi}.
  • Define 2D vectors like u = [3, 4], v = [−2, 1] at (1, 2), or combinations like u + v, and open Vector options to show magnitude |v|, angle θ, components, and tip-to-tail addition.
  • Plot derivatives directly as f'(x) and f''(x), or expand Calculus tools for tangent/secant lines and shaded area or Riemann sums (left, right, midpoint rectangles, trapezoids). Enter normpdf(x, 0, 1) for normal distribution shading and z-scores.

Entering & Pasting Data Tables

  • Click + Add table to create an (x, y) table. Navigate cells with arrow keys (pressing ↓ in the last row inserts a new row), or paste two columns copied directly from Google Sheets or Excel—text column headers are skipped automatically.

Scatter Plot & Point Options

  • Toggle Connect the points, Name the points A, B, C, and Show coordinates to format scatter plots or broken-line graphs.

Curve Fitting & Best-Fit Regressions

  • Choose a Best fit model from the dropdown: Linear, Quadratic, Cubic, Exponential, Logarithmic, Power, or Sinusoidal (with an optional fixed Period input).
  • The table footer shows the fitted equation and R² value (plus period, amplitude, and midline for sinusoidal fits).

Residual Plots & Promoting Fits to Function Rows

  • Check Show the equation on the graph to label the regression curve directly on the canvas, or check Show residual plot (y − ŷ) to plot residuals against x.
  • Click Add the best fit as a new row to copy the regression equation into a regular function row so you can inspect key points, intersections, inverses, or calculus properties.
