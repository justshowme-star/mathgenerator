Welcome to the Math Grapher

Add lines or points, label them, then set up the axes and grid. The graph updates as you type.

Lines and points

Type an equation, inequality or point. The symbol buttons insert at the cursor in whichever box you last clicked.

y = 2x + 1 y ≥ x − 3 x = 4 x² + y² = 9 f(x) = x² A(2, 3), B(−1, 4)

Press Piecewise for a fill-in editor, or type one line: f(x) = {x < 0: x + 1, 0 ≤ x < 2: x², 3}. A last entry with no condition covers everything else. Labels show it as a proper piecewise function.

Limit a graph with braces: y = x + 1 {−2 ≤ x < 4}. Use ^ for powers, / for fractions and sqrt( ) for roots. Letters like a, h and k become sliders.

Click the colored circle to show or hide a row. Press and hold it to change the color. For several points, name them in the label box as A; B; C.

Press + Add table for a data table. Type values or paste two columns copied from a spreadsheet, then choose a best fit, including sinusoidal, to see its equation and R².

Use the ⋯ button on a row to duplicate it, move it up or down, delete it, mark it as answer key only (hidden in the student copy), or copy or save the equation as an image, copy it for Google Docs, or copy it as LaTeX or plain text. Copy for Docs and Copy as image buttons also sit under each equation. The Key | Student and Color | B&W switches in the top toolbar toggle between the answer key and student copy, and between color and black and white.

Export & print

Save or print the graph as a picture. 1× matches the screen size; choose 2×–4× for sharper prints. Google Docs settings control how copied equations are formatted.

Working with the graph

Drag to move the view. Hold Ctrl (Cmd on a Mac) and scroll to zoom, or use the + and − buttons. After you click the graph, plain scrolling, the arrow keys and + and − also work. The view snaps to the grid when you let go. On a touch screen, tap ✥ to drag the graph; otherwise your finger scrolls the page.

Drag a label to place it (double-click it to reset). Click a line or point to edit its row.

Ctrl+Z undoes and Ctrl+Shift+Z redoes. Your work saves automatically in this browser.

Getting equations into Google Docs
  • Use the Copy for Docs and Copy as image buttons under an equation, or the same options in the row’s ⋯ menu.
  • Copy as image, click in your Doc and paste (Ctrl/Cmd+V). This works for everything, including piecewise functions. Resize it in Docs if needed.
  • Editable Docs equation: choose Copy for Docs equation, then paste it into your Doc. It is wrapped in $ … $ by default; change the wrapper in the Export ▾ menu in the top toolbar, or paste it into Insert → Equation without the $. Docs converts commands such as \frac, \sqrt and \pi when you press space after them. If pasted commands stay as plain text, click right after each command and press space.
  • Piecewise functions: Docs equations can’t draw these, so Copy for Docs equation copies them as a borderless table: a large brace beside one row per piece. Paste it straight into your Doc. Cells hold plain math text (x², √x, ≤) you can edit, or choose “Docs equation commands” to turn each cell into a Docs equation yourself. If borders show up, select the table and set the border width to 0.
  • If copying the image is blocked, open Export ▾, choose Save PNG, and insert it with Insert → Image.
Graph settings

Range & step: From and To set the visible range. Step is the distance between gridlines. Fractions and pi work, like pi/2. Dragging or zooming the graph updates these boxes when you let go.

Grid & titles: Adjust gridline weight, minor subdivisions, and square size. Axis labels default to x and y until changed, and powers like x^2 format automatically.
